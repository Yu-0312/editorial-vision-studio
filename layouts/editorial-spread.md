# Editorial Spread Layout

## DNA

| Element | Ratio |
|---------|-------|
| Image | 55–65% |
| Text / secondary image | 25–35% |
| Gutter whitespace | 5–10% |

## Structure

- Book or magazine spread feel
- Photo + supporting abstract strip or pull quote
- Horizontal or vertical depending on content

## Best when

Food editorial, product story, multi-element narrative

## Compiler anchor

```
Editorial spread, dominant photograph 60%, supporting abstract color band 30%,
book gutter whitespace, narrative pacing between image and type.
```
