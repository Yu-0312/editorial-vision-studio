# Moodboard Layout

For visual exploration, concept boards, material boards, color studies, or style frames.

## DNA

| Element | Ratio |
|---------|-------|
| Reference fragments | 45-60% |
| Color / material samples | 20-30% |
| Whitespace / labels | 15-25% |

## Structure

- Show relationships between texture, color, light, and composition
- Use labels only when the user requests annotated output
- Keep fragments coherent under one visual language
- Prefer generated references over direct imitation of living artists or brands

## Compiler anchor

```
Concept moodboard, coherent visual language, curated fragments of material,
color, light, and composition, generous whitespace, restrained annotation,
no copied brand marks, no messy collage.
```
