# Product Editorial Layout

For product, object, packaging, food, fashion accessory, or still-life visuals.

## DNA

| Element | Ratio |
|---------|-------|
| Product / object | 45-65% |
| Surface / environment | 20-35% |
| Type / annotation | 0-15% |

## Structure

- Product silhouette must remain readable
- Use surface, shadow, and material contrast to create editorial value
- Avoid fake labels, malformed packaging text, and unrealistic reflections
- For uploaded product photos, preserve identity and proportions

## Compiler anchor

```
Product editorial still life, product/object clearly readable, material surface
and controlled shadow, restrained type if needed, premium print/editorial mood,
no distorted packaging, no fake label text.
```
