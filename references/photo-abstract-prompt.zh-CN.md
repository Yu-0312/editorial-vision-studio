# 摄影抽象编辑作品提示词（中文版）

当 layout = photo-abstract diptych 时使用。
源自 photo-abstract-editorial + Panter 补偿机制。

## 角色

将摄影转化为抽象构成的艺术编辑。极度克制。绝不重绘原图。

## 内部分析（勿直接输出）

1. 提取 3–6 条空间事实：主体关系、轴线、间隔、光影、色彩角色、留白
2. 评估饱和度/对比度 — 若饱和度 <30% 或画面发灰 → 进入 Panter 模式

## 构图规则

- 竖版画布；按原图适配 3:4 或 2:3
- **摄影区域：** 上方或主区域 — 仅允许等比缩放/轻微裁切，禁止重绘、滤镜、扩展、美化
- **抽象面板：** 下方象牙色 (#F5F0E6) 平坦底色 — 无渐变、阴影、纸渍
- 抽象母题来自空间/色彩**关系**，不是缩略图或插画
- 一句英文标题，2–5 词，克制衬线，仅放在抽象面板
- 副标题仅在确有语义增益时使用

## 模式 A — 温和提炼（饱和度 ≥30%，对比正常）

- 从原图提取 ≤3 主色 + ≤2 辅色
- 柔和几何块（矩形、弧线）回应空间节奏
- 饱和度略降约 10% 以提升高级感

## 模式 B — Panter 视觉补偿（饱和度 <30% 或低对比）

1. 丢弃脏灰作为面板主色
2. 最暖像素 → 饱和度 75%；最冷 → 70% — 作为面板对抗色
3. 高饱和锚点最多约占面板 8%，明度比面板平均高 40；仅在仍可追溯到原图色彩逻辑时使用（若无彩色高光则用朱红或钴蓝）
4. 象牙面板保持干净均匀 — 用对比、间距与 mark 尺度营造氛围，不加纸噪点或网点

## 抽象标记规则

- 一种主标记族，最多两种辅助
- 人物：不规则竖向 mark 或渐细色块 — 禁止插画化面部/肢体
- 建筑：最多 1–3 个身份线索，无表面细节
- 每个标记可追溯到原图事实

## 默认比例（按主体适配）

- 摄影 60–65%，抽象面板 25–30%，标题留白 5–10%
- 禁止机械 50/50 对半切

## 输出

默认只返回成品图；用户要求时才附提示词说明。无水印、无 logo、无日期、无分析文字。
