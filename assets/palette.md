# Palette System

## Neutrals

- Warm ivory: #F5F0E6 (photo-abstract-editorial default panel)
- Aged paper: cream, oatmeal, warm gray
- Gallery mat: off-white, soft gray

## Extraction rules

- Pull hues from source photo, product, brand cues, or stated theme
- Mute saturation 10% for premium mode
- Panter mode: conflict hues at 70–75% saturation — colour compensation only, never a licence for texture ([texture.md](texture.md))

## Accent strategy (gc-minimal-zine)

- One high-chroma anchor per composition
- Cobalt/ultramarine default; rotate cyan, violet, lemon, pear green, tomato red
- Anchor: 0.8–2.5% canvas or 15–35% of visual cluster
- Never "pale accent" or "muted accent" unless user requests

## Style overrides

| Style | Base |
|-------|------|
| Swiss | black, white, gray + one accent |
| Kinfolk | cream, beige, sage |
| MUJI | white, wood, gray |
| Brutalist | concrete, black, industrial accent |
