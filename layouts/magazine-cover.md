# Magazine Cover Layout

## DNA

| Element | Ratio |
|---------|-------|
| Image | 65% |
| Typography | 20% |
| Whitespace | 15% |

## Structure

- Portrait-friendly vertical
- Subject with breathing room
- One masthead or title line — never overcrowded
- Optional thin rule or grid line

## Best when

Portrait + negative space >50%, strong subject clarity

## Compiler anchor

```
Magazine cover composition, portrait subject with large upper negative space,
single restrained serif masthead, 65/20/15 image-type-whitespace ratio.
```
