# Swiss Editorial — Style DNA

| Dimension | Level |
|-----------|-------|
| Typography | ★★★★★ |
| Geometry | ★★★★★ |
| Negative Space | ★★★★★ |
| Texture | ★★ |
| Lighting | ★★ |
| Color | ★★ |

## Characteristics

- Strict grid, mathematical spacing
- Minimal typography, grotesk or neo-grotesk
- Geometric balance, neutral palette
- One controlled accent maximum

## Typography

Helvetica, Neue Haas Grotesk, Akzidenz-Grotesk — small size, wide tracking

## Palette

Black, white, warm gray, occasional red or blue accent

## Compiler clauses

```
Swiss editorial grid, mathematical spacing, neo-grotesk caption typography,
neutral warm-gray palette, one precise red accent line, flat ivory ground.
```

## Mood

precise, intellectual, timeless
