# Campaign Poster Layout

For Event Campaign intent (TEDx, exhibition opening, brand launch).

## DNA

| Element | Ratio |
|---------|-------|
| Key visual / photo | 55–65% |
| Message hierarchy | 25–35% |
| Margin / bleed | 5–10% |

## Structure

- Bold readable hierarchy — event name > tagline > date/venue
- Key visual may be photo, abstract derived panel, or hybrid
- Adaptable to social banner (1:1 crop) and stage screen (16:9) via Planner note

## Style bias

Campaign Bold visual language → Swiss, Brutalist, or user override

## Compiler anchor

```
Event campaign poster, vertical 3:4, key visual 60% upper field,
bold grotesk event title in lower third, high-contrast graphic hierarchy,
flat print-ready composition, no mockup device frame.
```

## Intent constraint

Only when Intent family = Event Campaign. Do not use for gallery-only requests.
