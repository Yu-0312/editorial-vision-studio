# Typography System

## Serif (editorial default)

Garamond, Times New Roman, Caslon — small size, restrained

## Sans (Swiss / modern)

Helvetica, Neue Haas Grotesk, Akzidenz-Grotesk

## Mono / typewriter (zine)

Courier, IBM Plex Mono — fragmented, semi-legible ok

## Rules

- Never excessive text; 2–5 word title default
- Typography supports image, does not dominate
- MUJI cap: caption scale only
- Gallery: optional tiny caption or none

## Title language

Default English poetic title unless user specifies otherwise
