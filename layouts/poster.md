# Editorial Poster Layout

## DNA

| Element | Ratio |
|---------|-------|
| Main image | 60–70% |
| Graphic system | 20–30% |
| Negative space | 10% |

## Structure

- Vertical 3:4 or 2:3 (match source photo)
- Photo region top or dominant left
- Abstract panel or type zone secondary
- Title: minimal, small, balanced

## Variants

- Full bleed hero + bottom type strip
- Photo-abstract diptych (photo-abstract-editorial)
- Split layout with geometric side panel

## Compiler anchor

```
Editorial poster, vertical 3:4, main image 65%, graphic system 25%, margin 10%.
```
