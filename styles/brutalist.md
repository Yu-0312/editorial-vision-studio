# Brutalist Editorial — Style DNA

| Dimension | Level |
|-----------|-------|
| Typography | ★★★★ |
| Geometry | ★★★★★ |
| Negative Space | ★★★ |
| Texture | ★★★ |
| Color | ★★★ |

## Characteristics

- Bold type as object, raw concrete forms
- High contrast, asymmetric blocks
- Limited palette, industrial mood

## Typography

Oversized grotesk or monospace as graphic element — but not with MUJI layouts

## Palette

Concrete gray, black, white, one industrial accent (orange, yellow, blue)

## Compiler clauses

```
Asymmetric concrete-gray blocks, bold grotesk type fragment as graphic shape,
high contrast, raw matte surface, industrial editorial poster.
```

## Mood

raw, architectural, confrontational
