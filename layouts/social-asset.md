# Social Asset Layout

For square posts, vertical stories, carousel covers, or campaign social crops.

## DNA

| Element | Ratio |
|---------|-------|
| Focal visual | 50-65% |
| Message / type-safe area | 20-30% |
| Brand or color cue | 10-20% |

## Structure

- Choose aspect ratio from platform intent: 1:1, 4:5, 9:16, or 16:9
- Make the focal read at small sizes
- Keep typography minimal unless using Ideogram or user asks for text-heavy design
- Leave margins for platform UI overlays in story/reel formats

## Compiler anchor

```
Social campaign asset, mobile-readable focal visual, strong crop, clear
message-safe area, one brand/color cue, no clutter, no watermark.
```
