# Zine Layout

## DNA

Inherits gc-minimal-zine-poster grammar:

- Vertical 3:5 aged-paper canvas
- 70–90% negative space
- One small visual cluster (8–25%)
- Serif/typewriter/mono typography
- One high-chroma anchor (0.8–2.5% canvas)
- Xerox/riso/halftone defects

## Variation axes

Before compile, run [assets/variation-engine.md](../assets/variation-engine.md) — pick one option per axis.

## Compiler anchor

```
Tall vertical 3:5 aged paper, 80% empty field, one small visual cluster lower-left,
scanned-paper orthographic view, one saturated cobalt risograph anchor.
```

## Avoid

Commercial ad, glossy mockup, dense scrapbook, long clean text blocks
