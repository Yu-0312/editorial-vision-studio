# Website Hero Layout

For landing-page hero art, product-site visuals, SaaS hero images, or web campaign headers.

## DNA

| Element | Ratio |
|---------|-------|
| Focal visual | 45-60% |
| Copy-safe negative space | 30-45% |
| Atmospheric support | 5-15% |

## Structure

- Preserve a clear copy-safe zone on the left, right, or center according to request
- Use wide 16:9 by default unless user specifies otherwise
- Do not generate fake UI, fake dashboards, or tiny unreadable text unless requested
- Keep the visual calm enough to sit behind or beside real interface copy

## Compiler anchor

```
Website hero image, wide 16:9, focal visual 55%, clear copy-safe negative
space 35%, subtle atmosphere 10%, polished product-site art direction,
no fake UI text, no mockup device frame unless requested.
```
