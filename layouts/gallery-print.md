# Gallery Print Layout

## DNA

| Element | Ratio |
|---------|-------|
| Image | 92% |
| Typography | 3% |
| Whitespace | 5% |

## Structure

- Minimal intervention on photo
- Tiny caption or no type
- Museum quiet, generous mat

## Best when

Landscape, quiet atmosphere, high composition score

## Compiler anchor

```
Gallery print layout, image 92% canvas, tiny caption only,
museum mat whitespace, no decorative overlay, quiet contemplative mood.
```
