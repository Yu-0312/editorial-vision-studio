# 🎨 Editorial Vision Studio

> A modern AI-powered editorial and visual content creation studio.

Editorial Vision Studio is an intelligent content creation platform that combines AI text generation, visual editing, and workflow management to help creators produce high-quality editorial content faster.

## ✨ Features

- 🤖 AI-assisted content generation
- 📝 Rich text editor
- 🎨 Visual asset management
- 📂 Project-based workspace
- ⚡ Fast and responsive UI
- 🌙 Modern design
- 🔒 Secure authentication
- 📱 Responsive across desktop and mobile

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/Yu-0312/editorial-vision-studio.git
```

Enter the project

```bash
cd editorial-vision-studio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production version

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
