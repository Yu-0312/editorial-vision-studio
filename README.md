# 🎨 Editorial Vision Studio

> AI 驅動的編輯與視覺內容創作工作室

Editorial Vision Studio 是一套協助內容創作者進行企劃、編輯與視覺內容製作的工具，透過 AI 提升創作效率，讓從靈感到成品的流程更加快速且一致。

---

## ✨ 專案特色

- 🤖 AI 輔助內容創作
- 📝 編輯工作流程管理
- 🎨 視覺素材整合
- 📂 專案化管理
- ⚡ 快速且流暢的使用體驗
- 📱 支援多種裝置瀏覽
- 🔒 安全且易於維護

---

## 📁 專案結構

```
.
├── adapters/       # 適配器
├── agents/         # AI Agents
├── assets/         # 圖片與素材
├── layouts/        # 版面配置
├── prompts/        # Prompt 模板
├── reference/      # 參考資料
├── references/     # 文件資源
├── recovery/       # 回復與備份
├── spec/           # 專案規格
├── styles/         # 樣式設定
├── SKILL.md        # Skill 說明
└── LICENSE
```

## 🚀 使用方式

1. Clone 專案

```bash
git clone https://github.com/Yu-0312/editorial-vision-studio.git
```

2. 進入專案

```bash
cd editorial-vision-studio
```

3. 依照 `SKILL.md` 或相關文件進行設定與使用。
