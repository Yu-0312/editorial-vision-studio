# Brand Key Visual Layout

For brand launch, identity campaign, seasonal drop, or cross-format key visual.

## DNA

| Element | Ratio |
|---------|-------|
| Core brand image / object | 45-60% |
| Brand system cue | 20-30% |
| Copy-safe space | 15-25% |

## Structure

- Build one memorable visual sign, not a busy collage
- Preserve logo/type space if brand assets or campaign copy are provided
- Keep palette and material cues traceable to the brand or product
- Prefer adaptable composition that can crop to 1:1, 4:5, and 16:9

## Compiler anchor

```
Brand key visual, adaptable campaign composition, core visual sign 55%,
brand-system cues 25%, copy-safe negative space 20%, restrained hierarchy,
no fake logo, no mockup frame unless requested.
```
