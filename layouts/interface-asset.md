# Interface Asset Layout

For empty states, app backgrounds, onboarding visuals, lightweight illustrations, or product UI imagery.

## DNA

| Element | Ratio |
|---------|-------|
| Main symbolic object | 35-50% |
| Empty / UI-safe space | 35-50% |
| System color cue | 5-15% |

## Structure

- Support the interface; do not compete with it
- Avoid fake controls, fake charts, tiny labels, or unreadable text
- Match the app's tone: utility, calm, playful, premium, or technical
- Prefer simple silhouettes, abstract systems, or material metaphors

## Compiler anchor

```
Interface asset, clean symbolic visual, generous UI-safe whitespace,
small system color cue, calm app-ready composition, no fake UI controls,
no unreadable text.
```
